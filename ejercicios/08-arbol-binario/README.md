# Reto 08: árbol binario de búsqueda

Fuente: `material-clase/Clase 09 - Árboles.pptx`, diapositiva 18.

`demo.js` inserta una serie de números y muestra inorden, postorden y
preorden por consola. `contiene` busca un valor sin recorrer ramas innecesarias.
`paraD3` adapta los nodos al formato `{ name, children }` usado por
`react-d3-tree` en la página React.

Ejecuta `npm run demo:arbol` desde la raíz. Guía: `guias/02-arboles.md`.
