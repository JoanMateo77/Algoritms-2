# Reto 09: árbol N-ario de menús

Fuente: `material-clase/Clase 09 - Árboles.pptx`, diapositiva 24.

Cada nodo guarda título, enlace, componente e hijos. `menus.js` construye el
árbol; `dfs`, `bfs` y `buscar` permiten recorrerlo. La pantalla React dibuja
una barra lateral recorriendo los hijos, y muestra el componente asociado al
enlace seleccionado.

Ejecuta `npm run demo:menus` desde la raíz. Guía: `guias/02-arboles.md`.
