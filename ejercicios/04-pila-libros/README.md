# Reto 04: pila de libros

Fuente: `material-clase/Clase 06 - Pilas y Colas (1).pptx`, diapositiva 7.

Cada libro tiene nombre, ISBN, autor y editorial. Hay datos de ejemplo, una pila
con `push`, `pop`, `peek`, `size`, `isEmpty` y `print`, y una pantalla React con
formulario y visualización de la pila.

Ejecuta `npm run demo:pila` desde la raíz o abre la página **Pila** en la app.
La guía de estudio está en `guias/01-pilas-y-colas.md`.
